導入ガイド

Ulexite TV は、VRChat のワールドに置くテレビです。ワールドにある動画プレイヤーの画面に、本体の電源を入れているあいだだけ Ulexite の画面を映します。

はじめに

Ulexite TV は、VRChat のワールドに置く、Android TV 風のテレビ（セットトップボックス）です。ホームにアプリが並び、リモコンの十字キーと決定だけで操作できます。動画の再生と同期は VizVid（MIT ライセンス）が受け持ち、Ulexite は「テレビを見る体験」を受け持ちます。

いまはテスト版を、試してくださる方に個別にお渡ししている段階です。VCC と BOOTH からの配布は、公開の準備ができてから始めます。Ulexite Store（デモワールド）は、VRChat の Community Labs で公開しています。

Ulexite は架空のブランドです。実在の企業とは関係ありません。制作は葛城ひなた（@k_hinata_vrc）です。

必要なもの

ものバージョン・用意のしかた
Unity2022.3.22f1
VRChat Worlds SDK3.10.5 以上（UdonSharp は SDK に含まれます）
VizVid（idv.jlchntoz.vvmw）1.8.2 以上 1.9 未満。公式の説明に沿って VCC から追加します
VCC（VRChat Creator Companion）ワールドのプロジェクトを作るのに使います

VizVid は、Ulexite TV を入れるときの依存として一緒に入ります。

入れ方（テスト版）

  1. VCC でプロジェクトを用意する

    VCC でワールドのプロジェクトを作り、「Manage Project」から VizVid を追加します（必要なパッケージも一緒に入ります）。

  2. Unity でプロジェクトを開く

    Unity 2022.3.22f1 でプロジェクトを開きます。

  3. .unitypackage を入れる

    UlexiteTV-0.3.0.unitypackage を Project ウィンドウにドラッグし、「Import」を押します。Packages/Ulexite TV に入ります。

  4. VizVid のプレイヤーを置く

    VizVid の説明に沿って、プレイヤーをシーンに1つ置きます。VizVid の画面や操作パネルは使わないので、見えないところに置いても大丈夫です。音は VizVid のスピーカーから出るので、スピーカーは映す画面の近くに置いてください。

  5. 本体を作る

    上のメニューの「Tools → Ulexite → セットトップボックスを作成」を押し、できた白い本体をテーブルなど置きたい場所へ動かします。

  6. 映す画面を選ぶ

    「Tools → Ulexite → 設定」を開き、左の「はじめに」を選びます。「セットトップボックス版」の欄で、Hierarchy から既存のプレイヤーのスクリーン（画面のオブジェクト）を選び、「選んでいる物を足す」を押します。マテリアルが複数ある画面は、映像が出ているマテリアルを選んでください。

  7. テレビに反映する

    「テレビに反映（作り直す）」を押します。リモコンがなければ本体の右隣に自動で作られます。

    「U# をコンパイルし直しています」と出たら、Console に「Compile of … scripts finished」が出てから、もう一度押してください。

  8. 確かめる

    シーンを保存し（Ctrl＋S）、VRChat SDK の「Build & Test」で確かめます。

左右・上下が逆に映るときは、Assets/Ulexite/Generated/SetTopBox/UlexiteScreen.mat の Tiling を -1 にしてください。

公開後の入れ方（準備中）

公開後は、VCC の「Add to VCC」ボタンと BOOTH のページから入れられるようにする予定です。URL と手順は、公開の準備ができてからここに載せます。

画面の映し方

今はワールドにある画面に映す形です。カメラで描いた映像を、その画面のマテリアルに差し替えます。

  • テレビを置くだけで、ワールドの見た目は変わりません（電源を入れるまで、元のプレイヤーの画面が見えています）
  • 映した先の画面では、レーザーで押す操作はできません。操作はリモコンで行います
  • 本体と画面は、いくつでも置けます。本体ごとに別のテレビとして動きます

画面つきの形（同梱の画面に UI を置く形）は準備中です。

使い方

電源

本体の手前左の電源マークを押します（オンでランプが青、オフで灰色）。ワールドに入ったときはオフで、元のプレイヤーの画面が見えています。

リモコン

リモコンを持ってから操作モードに入ります（VR は A ボタン、デスクトップはスペースか Tab）。持っただけでは歩けます。

したいことVRデスクトップ
選ぶ場所を動かす左スティック矢印キー
決める持っている手のトリガーEnter
操作モードに入るA ボタンスペースか Tab
  • 決定の長押し：アプリのタイル（ホーム・アプリタブ）のメニュー（起動・アプリ情報・ホームから外す・並べ替え）
  • 通知ウィンドウ：画面右上の時計を選んで決定
  • 戻る・ホーム・設定：画面の上のナビゲーションバー
  • 呼び戻し：本体の手前右のアイコンを押すと、リモコンが本体の右隣に戻ります

操作するとき、リモコンを持っている人がテレビと再生の操作権を持ちます。ほかの人がレーザーで押したときは、その人が画面の操作権を持ちます（リモコンの持ち主は変わりません）。

動画アプリを使うとき

動画アプリでは、YouTube の公式ロゴを同梱していません。「Tools → Ulexite → 設定」の「はじめに」にある「YouTube のロゴ」の欄で、次の順に入れてください。

  1. 「ブランドリソースのページを開く」でガイドラインを確認し、暗い背景用のロゴ（PNG、または zip）をダウンロードする
  2. 「ダウンロードしたファイルから入れる…」でそのファイルを選ぶ（Assets/Ulexite/Brand/ に入り、テレビを作り直します）

ロゴは改変しないでください。動画アプリを初めて使うときは、YouTube API Services を使うことの案内が出ます。

わかっている制限

  • 映した先の画面では、レーザーで押す操作はできません（操作はリモコンで行います）
  • Ulexite の電源を入れても、元のプレイヤーの音は止まりません。両方を流すと音が重なります
  • 映す画面が曲面だったり、プレイヤーがマテリアルそのものを入れ替える作りだったりすると、うまく映らないことがあります
  • Quest での動作は、これから確認します

うまくいかないとき

  • まず「Tools → Ulexite → テレビを作り直す」を押し、シーンを保存してから Build & Test で確かめてください
  • 画面が上下・左右に逆に映るときは、UlexiteScreen.mat の Tiling を -1 にします
  • U# をコンパイルし直している間は、Console の「Compile of … scripts finished」を待ってからもう一度押します

不具合を見つけたら、次のものを添えて教えてください。

  • Ulexite TV のバージョン（「Tools → Ulexite → 設定」の右上）
  • 起きたこと、やった操作
  • Unity の Console の赤い行（エディタで起きたとき）、または VRChat のログ（%USERPROFILE%\AppData\LocalLow\VRChat\VRChat\output_log_*.txt）

ライセンスと応援

Ulexite TV は無料です。ライセンスは VN3 ライセンスで、次のことができます。

  • 改変と、無償での再配布
  • ワールドでの利用（商用のワールド・有料イベントでも使えます）
  • クレジットの表記は任意

販売はできません。改変したものに Ulexite の名前とロゴは使えません。くわしくは利用規約（VN3 ライセンス）を見てください。

気に入ったら、BOOTH のお布施で開発を支えていただけるとうれしいです（準備中）。
