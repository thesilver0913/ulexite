Ulexite TV 0.3.02026年10月20日テスト版

確かめてから消す。展示でも使える。

動画アプリの操作に確認を足し、展示用のデモモードと、操作を案内する体験ガイドを入れました。本体とリモコンの見た目も、製品の 3D モデルに変わっています。

新しいもの

  • 確認ダイアログ：動画アプリの「履歴を消す」の前に、確認が出るようになりました。答えるのはリモコンを持っている人です。危ない操作では、最初のフォーカスが「いいえ」に置かれます
  • 共有データ：アプリの設定を、その場の全員で分け合えるようになりました（Ulexite App Services の第2段階）。書けるのは操作している人で、ほかの人は依頼します
  • デモモード（展示用）：本体の Inspector でオンにすると、誰も触っていないあいだは体験ガイドの紹介が待ち受けに出ます。リモコンを手に取ると「やってみよう」が始まり、ホーム・設定・ストアには出られません
  • 本体とリモコンの見た目：製品の 3D モデルになりました。押せる場所・ランプ・持ち方は同じです
  • メニューの整理：「Tools → Ulexite」は、制作者が使うもの（設定・テレビを作り直す・セットトップボックスを作成）だけになりました

入れ替えるとき

0.2.0 から入れ替えたときは、「テレビに反映（作り直す）」のあと、「Tools → Ulexite → セットトップボックスを作成」で「作り直す」を押してください。

テスト版のため、設定や画面の作りは次の版で変わることがあります。気づいたことは、バージョンと一緒に X の @UlexiteOfficial までお知らせください。

Ulexite TV 0.2.02026年10月16日最初のテスト版

はじめて、友人に配った版。

セットトップボックス版として、ひととおりの機能がそろった版です。ここから、実際にワールドで使ってもらいながら直しています。

  • ホーム、アプリタブ、通知ウィンドウ
  • 動画アプリ、URL プレイヤー、VRC 放送局、ライブラリ
  • リモコンと画面の操作の同期、10秒送り・戻し
  • 設定、スクリーンセーバー、おやすみタイマー、ポータブルディスプレイ
  • お知らせとエラー画面、日本語と英語の表示

Ulexite 開発キット 0.1.02026年10月20日

アプリを作るための道具を、ひとつに。

VCC で1つ入れると、Ulexite TV と VizVid、アプリを作るための道具がそろいます。

  • 足りないものの確認（Unity・SDK・VizVid・TextMeshPro）
  • VCC にリポジトリを足すリンク（Ulexite と VizVid を一度に）
  • 「新しいアプリ」ウィザード（データで書くアプリ／U# のアプリ）
  • 見本のアプリ（ハローワールド・天気）と、テスト用のシーン
  • 申請の前の検査と、Ulexite Emulator

VCC への配布は、Ulexite TV の公開に合わせて始めます。
